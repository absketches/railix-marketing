# Railix Marketing Website

Static public-facing marketing website for Railix.

## Structure

- `index.html` - overview page
- `model.html` - Railix model and Creator positioning
- `run-anywhere.html` - self-hosting, serverless and edge deployment story
- `use-cases.html` - strong and weaker production fits
- `security.html` - access, production visibility and secrets positioning
- `contact.html` - static contact page with a copyable email draft
- `styles.css` - shared site styles
- `i18n.js` - German/English language switch behavior
- `messages/` - per-language message files
- `public/` - static assets

## Local Preview

Open `index.html` in a browser.
